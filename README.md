# 考勤打卡系统 - 微信公众号版

## 功能说明
- 发送「上班」→ 记录上班打卡时间
- 发送「下班」→ 记录下班打卡时间，自动计算工时和加班费
- 发送「查询」→ 查询当日考勤
- 发送「汇总」→ 查询本月考勤汇总（周期：上月26日~当月25日）
- 发送「底薪」→ 查看当前底薪配置
- 发送「设置用户名 张三」→ 设置自己的名字
- 发送「帮助」→ 查看功能列表

## 加班费计算规则
- 小时工资 = 底薪 ÷ 21.75天 ÷ 8小时
- 工作日超8h：**1.5倍** | 休息日（周末）：**2.0倍** | 法定节假日：**3.0倍**
- 午休 11:30~13:00（1.5h）不计入工时
- 无打卡记录的工作日默认8h出勤，周末节假日默认休息

## 管理员功能 (Web后台)
- 设置员工底薪、查看所有考勤记录
- 补卡、导出Excel报表（含汇总表+明细表）
- 节假日管理（支持批量导入）

```bash

python app.py           # 访问 http://localhost:5000/admin
```
